### 단위와 기하 기준

- 지수 교체율 $\gamma_t=1/\tau$의 내부 단위는 **s⁻¹**. UI가 $\gamma_t/(2\pi)$를 kHz로 받는다면 $\gamma_t=2\pi\cdot10^3\,x_{\mathrm{kHz}}$. 이미 s⁻¹로 받은 값은 그대로 쓴다. 지수적인 완전 교체가 광학 결맞음을 감쇠시킬 때 추가 HWHM은 $\gamma_t$ rad/s, 추가 FWHM은 $\gamma_t/\pi$ Hz. 관측 스펙트럼 FWHM은 전체 선모양에서 따로 구한다.
- 가우시안 **세기** $I(r)=I_0e^{-2r^2/w^2}$. $w$는 $1/e^2$ 반경. $d_{1/e^2}=2w$, $D_{\mathrm{FWHM}}=w\sqrt{2\ln2}$, $I_0=2P/(\pi w^2)$. 운동 온도 $T_{\mathrm{kin}}$과 동위원소 질량 $m$으로 열속도를 구한다. 증기압을 정하는 저온부 온도는 별도 입력이다.
- Häupl 식 (8)의 수치 관례를 그대로 적용하면 ⁸⁵Rb, 99 °C, $w=530$ µm에서 $D_{\mathrm{FWHM}}\approx624$ µm, $\tau\approx2.05$ µs, $\gamma_t/(2\pi)\approx77.7$ kHz. 논문의 $\sqrt{8k_BT/(\pi m)}$는 3차원 Maxwell 평균 속력과 수치가 같다. 원형 경계를 가정하면 횡속력의 Rayleigh 평균과 평균 현 길이 $\pi D/4$의 비도 같은 값이다. 이 조합을 한 묶음으로 식별한다. $w/\langle v_\perp\rangle$ 같은 다른 기하 관례는 별도로 명시한다.
- 궤적 기준 해는 충돌 없는 단일 빔에서 $I(t)=I_0\exp[-2(b^2+v_\perp^2t^2)/w^2]$를 따른다. 진입 플럭스, 빔 안의 점유 수, 검출 모드 가중을 각각 정의한다. 예를 들어 측면으로 유입하는 모델의 속력 분포에는 벌크 분포 대비 $v_\perp$ 가중이 붙는다. 궤적상의 원자 상태를 풀고 관측량을 평균한다. 느린 원자·중심을 비껴가는 원자·공간 절단 오차를 확인한다.

## 공통 모듈 설계

**`gabes/transit.py` 후보.** 단위 변환, Gaussian 반경 관례, 명시한 기하·운동·질량으로부터 속도와 체류 척도를 계산한다. 선택된 공식과 적용 조건은 모델 ID·버전·출처로 추적한다. 내부는 s⁻¹, m, K, kg를 사용한다. 스킴은 실제 적용 위치를 지정한다. 반환 형태는 필요한 곳에서만 도입한다. 계산 결과에는 `rate_s_inverse`, `residence_time_s`, 모델 ID와 입력 관례를 포함할 수 있다. OD는 열적 교체와 광학 결맞음, Rydberg는 지정한 결맞음, Magneto는 빔 안팎의 교환이다. Λ·Biphoton처럼 해당 채널에 기하 모델이 없는 경로에는 적용 여부를 명시한다.

밀도행렬의 열적 교체는 [`AtomModel.with_reset`](../gabes/atoms.py#L66), [`core.thermal_reset_superoperator`](../gabes/core.py#L151), 잡음 채널은 [`quantum.reservoirs.thermal_reset_channels`](../gabes/quantum/reservoirs.py#L112)를 재사용한다. 같은 과정이 인구·결맞음 식에 미치는 영향을 검사하고, 같은 물리적 손실을 독립 감쇠율로 또 더하는 경우를 막는다. Maxwell 속도 표준편차는 기존 `constants.thermal_speed`를 쓴다. 빔 안팎 왕복 솔버와 완충기체 확산은 현재 모듈이 맡는다. 두 곳 이상에서 쓸 단일 빔 궤적 계산이 검증되면 경로·가중 적분만 `gabes/transit_trajectories.py` 후보로 분리한다. 다중 빔 겹침, 벽 충돌, 잡음 상관, 스킴별 OBE는 해당 모델이 맡는다.

## 구현·검증 체크리스트

### A. 현재 계산을 보존하는 공통화

- [x] 위 표에 맞춰 각 호출 경로의 활성 조건, 값, 단위, 적용 연산자, 기준 위치, 모델 ID를 스냅샷에 기록한다. 모든 스킴의 기본·슬라이더 양 끝·기존 저장 설정, 서브모드와 추가 보기의 원시 배열·표시 판독을 저장한다. `gabes_lab.blocks.snapshot`을 재사용한다.

### ⁸⁵Rb D₁ 빔 횡단 이력 모델

무코팅·무완충 순수 ⁸⁵Rb 셀에 선형 편광 프로브 하나를 입사시킨다. 원자는 빔에 들어올 때 바닥상태 자기 부준위에 열평형 분포한다. 영자장에서 편광축을 기준으로 같은 $|m|$의 점유율을 묶으면 14개 율방정식이 남는다. 각 궤적을 따라 세기가 바뀌므로 빔을 나갈 때까지 점유율을 이어서 적분한다. 광학 반치반폭에는 자연폭과 자체 충돌폭, 명시한 추가 균일폭이 들어간다. 열평형 원자 공급은 입사 경계에 한 번만 적용한다.

충돌 파라미터 $b$와 횡속력 $v_\\perp$에 대해 입사 플럭스로 흡수 광자 수를 평균한다. 플럭스에 들어가는 $v_\\perp$와 선요소의 체류시간 $dx/v_\\perp$는 약한 빛에서 상쇄되어 기체의 열평형 속도분포를 회복한다. 빔과 평행한 속도는 원자 기준 디튜닝에서 계산한 단면적을 1차원 Maxwell 분포로 평균한다. 광파워는 각 단면에서 평균한 흡수에 따라 감소한다. 이때 횡방향 세기 분포는 단면마다 같은 반경의 가우시안으로 근사한다. 검출기는 출구 빔 전체를 수광한다.

⟦AI⟧ **단일 궤적의 물리 검산.** 99 °C, 100 µW, 반경 0.53 mm에서 실측 양쪽 안쪽 날개의 중앙 통과($b=0$, $v_\\perp=191$ m/s)를 24준위 시간 의존 OBE와 대조했다. $v_z=0$과 각 날개에서 가장 가까운 전이에 공명하는 속도군(+442, −345 m/s)을 포함한 네 경우, 영자장 흡수 광자 수의 상대차는 최대 0.018%였다. OBE의 적분 단계를 768에서 1,536으로 늘렸을 때 변화는 $1.7\\times10^{-9}$ 이하였다. 편광축에 수직인 50 µT를 가정하면 공명 속도군의 흡수 광자 수는 영자장 대비 29%와 33% 증가했다. 이 값은 한 궤적의 민감도다. 실측 셀은 자기 차폐가 없었고 자기장 벡터는 미측정이다.

### 펌프를 끈 Rb 혼합물과 D₂

영자장·선형 편광·무완충·무코팅인 균일 셀에서는 ⁸⁵Rb와 ⁸⁷Rb 각각의 D₁·D₂ 횡단 이력을 계산할 수 있다. 한 단면에 도달하는 광파워는 두 동위원소에 공통이다. 국소 흡수계수는 각 동위원소의 단면적에 흡수체 밀도 fᵢN을 곱해 더하며, 이 합으로 다음 단면의 광파워를 구한다. 전체 Rb 밀도 N은 각 동위원소의 자체 충돌폭에도 들어간다. 기록된 모델 ID는 당시의 밀도 규약을 쓴다. 자연·사용자 혼합비의 화면 디튜닝은 ⁸⁵Rb 중심 기준이며, 순수 ⁸⁷Rb 화면은 ⁸⁷Rb 중심 기준이다.

D₂ 율방정식은 서로 다른 들뜬 초미세 준위 사이의 결맞음을 생략한다. 99 °C, 반경 0.53 mm, 100 µW에서 정상상태 전체 OBE와 비교한 도플러 평균 단면적의 차이는 검사한 D₂ 안쪽 날개에서 최대 0.45%, ⁸⁵Rb D₂의 F=2 흡수군 중심에서 1.76%였다. 같은 파워에서 특정 단일 속도군의 횡단 중 흡수 광자 수는 최대 17.5% 차이가 났다. 이 수치로 셀 출구 투과율 오차를 정할 수 없다. 지구 자기장 크기의 횡자장, 큰 흡수 기울기, 얇은 셀, 고밀도에서의 형광 재흡수는 별도 모델이나 실측을 필요로 한다.

기존 ⁸⁵Rb D₁ 표의 범위를 벗어난 동위원소·전이선에서 Fast는 기준 해와 같은 경로 적분을 사용한다. 동위원소·선종·고유 광학폭·중심 세기·디튜닝이 같으면 횡단시간 w/√(k_BT/m)이 같은 궤적을 재사용할 수 있다. 종방향 Maxwell 평균과 광전파는 실제 온도와 밀도로 다시 계산한다. 새로운 조건을 처음 계산하는 데에는 기준 해와 비슷한 시간이 걸린다.


⟦AI⟧ **Fast v2 계산.** 95–107 °C를 0.5 °C 간격으로 나눈 25개 온도에서 원자 기준 디튜닝 272점과 물리 세기 18점의 비선형 흡수 단면적 보정분을 저장한다. 중간 온도에서는 인접한 네 온도점에서 같은 적분 패널의 대응점을 3차 보간한다. 열적 약한 프로브 Voigt 항, 디튜닝별 Maxwell 가중치, 밀도, 축 방향 광파워 감쇠는 요청 조건에서 계산한다. 실측 CSV는 검증에만 사용한다. 파일이나 원천 계산의 지문이 달라지면 기준 해를 직접 계산한다. 표는 `python -m gabes_lab.tools.build_ballistic_fast_table`로 재생성할 수 있다.

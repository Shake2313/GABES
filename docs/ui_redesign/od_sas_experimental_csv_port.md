# OD/SAS 이론 계산과 실험 OD 피팅 이식안

2026-11-20 · 설계 제안 · 기준 배포본 AutoOD 0.2.2

사용자 요청은 AutoOD에서 개선한 실험 CSV 비교 기능을 GABES 웹으로 가져오고, AutoOD의 디자인 규약에 GABES 색상을 적용하는 것이다. GABES 전체 화면에 카드와 옅은 그라데이션을 도입하는 작업은 CSV 통합 이후에 진행한다. 추가 사용자 결정으로 실험 화면은 펌프 없는 OD 전용으로 하고, 이론 화면의 펌프 설정은 보존한다. 단일 빔 Rb OD에서 더 상세한 AutoOD 모델을 GABES 공용 엔진으로 통합한다. 아래 영문 이름과 구현·검증 방식은 제안이며 진행 상태는 [제품 체크리스트](../checklist.json)에 기록한다.

## ⟦AI⟧ 사용자가 실험 파일을 비교하는 흐름

왼쪽 **Simulate spectra**(스펙트럼 계산)가 기본 화면이다. 펌프 설정에 따라 OD와 SAS 이론 스펙트럼을 계산한다. 오른쪽 **Fit OD data**(실험 OD 피팅)는 원자·전이선·셀·프로브 조건을 이어받고, 별도의 펌프 빔 없이 계산한 OD를 실험 데이터에 맞춘다. 예전 CSV 직접 링크 `?compare=0`는 오른쪽 화면으로 연결한다. 첫 화면에서 필요한 행동은 파일을 올리는 것 하나다. 파일이 열리면 어떤 열과 단위를 읽었고 어떤 곡선과 비교하는지 한 줄로 보여 준다. 예를 들어 “OD 채널 CH3 · 취득 순번 · 상대 신호”로 표시하고, 잘못 골랐으면 그 자리에서 바꾼다. 아래 표의 한글 문구는 동작의 의미를 나타내며 웹 버튼 표기는 기존 GABES 화면 언어를 따른다.

| 사용자 행동 | 화면과 데이터의 동작 |
|---|---|
| 파일 열기 | 일반 측정 CSV, AutoOD 비교 CSV, Origin 3줄 헤더, 트리거·SAS·OD가 함께 있는 오실로스코프 파일을 판별한다. 명시한 투과율 열을 참조광보다 우선한다. 채널 후보가 모호하면 직접 선택하고, 자동으로 쓴 채널·스캔 구간을 표시한다. SAS·트리거 채널은 파일 판별과 스캔 구간 식별에 활용한다. 피팅 대상은 OD 채널이며, OD를 구분하기 어려우면 측정자가 해당 열을 지정한다. |
| 축과 신호 확인 | X는 주파수 또는 임의 단위, Y는 투과율 0–1·%·상대 신호를 구분한다. 기존 GABES의 검출기 암신호·참조 신호 또는 검출기 이득·오프셋 보정도 제공한다. 이미 보정한 주파수축은 첫 피팅에서 배율 1·이동 0으로 연다. 단위만으로 주파수 영점을 추정하지 않는다. |
| 빠른 피팅 | 현재 이론 곡선과 대응하는 구간을 찾아 X를 맞춘다. 후보는 원래 측정점으로 검증한다. 여러 개면 후보 수를 알리고, 없으면 “범위만 맞춤”으로 표시한다. X·Y 배율, 이동·반전·초기화는 곡선 옆에서 조절한다. 표시용 Y 조정은 범례에 밝히고 절대 투과율 보정과 구분한다. |
| 확대·판독 | 전체 스펙트럼에서 선택 구간의 가운데나 양 끝 손잡이를 끈다. 아래에서 확대된 T·OD와 선택 주파수의 이론값을 함께 읽는다. 가장 가까운 실측점의 주파수와 값을 별도로 표시하고, 측정 공백이면 “측정점 없음”을 표시한다. 상대 신호에서 실험 OD를 산출하지 않는다. |
| 정밀 피팅 | 그래프 아래에 인라인 패널을 연다. 확대 구간과 별개로 피팅 구간을 지정하고 추정할 변수와 범위만 고른다. **피팅 후 적용**이 성공하면 해당 축과 조건을 함께 반영한다. 취소·실패하면 직전 값으로 돌아간다. 재실행 시 현재 D₁/D₂와 수동 정렬값을 우선한다. |
| 저장·다시 열기 | 원본 취득 행과 보정·표시·이론 격자 보간 열을 구분해 일반·Origin CSV로 내려받는다. 왕복 스캔은 두 방향의 행과 취득 순서를 모두 보존하고 중앙값 곡선을 표시할 때 이를 알린다. GABES의 기존 그림·JSON 내보내기도 유지한다. |

데스크톱에서는 위에서부터 **OD Conditions와 프로브 파워 → 실험 파일·빠른 피팅 → 전체 그래프 → 확대 그래프와 선택점 카드** 순서로 읽는다. 셀 온도를 두 곳에서 바꾸는 일이 없도록 기존 Conditions가 실제 조건의 기준이 된다. 파일을 올린 후에는 그래프와 자주 쓰는 정렬 조작을 함께 볼 수 있게 하고, 검출기 보정과 정밀 피팅은 필요할 때 아래에서 펼친다. 좁은 화면은 확대 그래프 다음에 결과 카드를 한 열로 쌓는다. 드래그에는 키보드로도 도달할 수 있는 구간 양 끝 수치 입력과 선택점 이동 조작을 함께 둔다. 공통 조작은 [D17](decisions.md#d17), 실험 보기의 펌프 처리와 이름은 [D20](decisions.md#d20)을 따른다.

### 펌프 설정의 보존과 복귀

| 동작 | 실제로 사용할 조건 |
|---|---|
| 이론 → 피팅 | 이론 화면의 마지막 펌프 파워·펌프 빔 반경·축방향 펌프 감쇠 설정을 세션에 그대로 둔다. 피팅용 조건 사본은 펌프 0 mW, 펌프 감쇠 꺼짐으로 구성한다. 프로브 파워·반경과 셀 조건은 현재 입력을 따른다. |
| 피팅 화면 사용 | 펌프 파워·반경·감쇠, SAS 프리셋·펌프 스캔·파생 판독값을 숨긴다. 이론선, 빠른 피팅, 정밀 피팅, 캐시 키, 내보낸 모델 정보가 모두 같은 펌프 없는 조건을 사용한다. 보관한 펌프 반경이 바뀌어도 OD 계산 결과와 캐시 키는 같다. |
| 적용·취소·복귀 | ‘피팅 후 적용’은 승인된 OD 공통 변수와 정렬값만 반영한다. 성공·취소·실패 및 보기 왕복 후에도 이론 화면은 이전 펌프 설정으로 다시 그린다. 피팅용 0 mW가 저장 프리셋을 덮어쓰지 않도록 저장·불러오기에서도 화면별 조건을 구분한다. |

예를 들어 이론 화면에서 펌프 3 mW, 반경 1.4 mm, 프로브 100 µW를 설정한 뒤 오른쪽으로 이동하면 펌프 0 mW와 프로브 100 µW로 계산한다. 오른쪽에서 온도 피팅을 적용하고 돌아오면 새 온도에 펌프 3 mW·반경 1.4 mm가 함께 적용된다. 직접 링크로 처음 들어오거나 브라우저 뒤로·앞으로를 사용해도 같은 규칙을 적용한다.

Tk 대화상자·도구 모음 대신 웹의 파일 업로드, 인라인 편집, 다운로드로 연결한다. |

구현을 시작할 때의 대조 소스는 AutoOD 0.2.2의 `autood/engine.py`(열 선택·왕복 출력), `scope_csv.py`·`scope_channels.py`(취득 구간·채널), `quick_alignment.py`(후보 검증), `spectrum_fit.py`·`fit_dialog.py`(구간·추정·적용)다. 비교 기준 ZIP의 SHA-256은 `0072a901fd9a5a1a9f61283a2d87e1c91c712da51df14ca2bcd47df0dca118df`다. 공용 코드를 추출할 때는 같은 입력에서 양쪽 원본·보정 배열과 판독값을 대조한다.

원본 취득점, 스캔 방향별 데이터, 화면용 정렬 곡선에는 서로 다른 역할이 있다. 중복 주파수를 합치거나 노이즈를 제거해도 원본 행은 유지한다. 검출된 측정 공백은 전체·확대·드래그 미리보기와 내보내기에서 같은 경계로 끊는다. 화면 전송 시에는 구간 끝점과 극값을 보존해 점을 줄일 수 있다. 정밀 피팅과 내보내기는 서버의 원본 또는 명시적으로 선택·보정한 측정점을 사용한다.

파일과 설정은 브라우저 세션의 작업 상태로 보관한다. 왕복 탐색 후에도 파일·단위·정렬·구간을 복원한다. 파일을 교체하거나 지우면 이전 파일에 종속된 피팅 결과를 해제한다. 피팅 요청에는 파일 식별값, 보정·스캔 방향, 구간, 이론 조건과 모델을 묶는다. D₁에서 시작한 계산이 끝나기 전에 D₂로 바꿔도 늦은 결과가 현재 D₂를 덮어쓰지 않아야 한다. 커서·확대·표시 배율은 브라우저에서 즉시 움직이고 손을 놓을 때 한 번 반영한다. 이 동작과 다운로드로 무거운 이론 계산이 다시 돌아서는 안 된다.

## ⟦AI⟧ 공통 OD 모델 채택 기준

**채택 범위는 균일하고 등온인 무코팅·무완충가스 Rb 셀, 영자기장, 단일 선편광 프로브의 D₁/D₂다.** 양의 프로브 파워에서 GABES의 일반 경로는 유효 2준위 포화를 쓰고, 별도의 광펌핑 참조 경로는 한 초미세 준위 안의 자기 부준위에 균등 점유를 가정한다. AutoOD는 선편광의 선택 규칙과 자발 방출 분기에 따라 자기 부준위의 점유가 재분배되는 과정까지 계산한다. 펌프 빔이 꺼져 있어도 프로브가 구동하는 광펌핑은 유효하다. 라만 결맞음과 자기장에 의한 세차는 이 모델의 범위 밖이다.

**같은 입력에서의 계산 대조.** 자연 Rb D₂, 25 °C, 셀 길이 75 mm, 1/e² 빔 직경 2 mm, 펌프 0 mW, 통과 완화율 γₜ/(2π) = 100 kHz를 양쪽에 입력했다. ⁸⁵Rb D₂ 중심에서 +1.6503615363 GHz인 동일 격자점의 투과율이다.

| 프로브 파워 | 현행 GABES 일반 모델 | AutoOD 0.2.2 | 차이(AutoOD − GABES) |
|---|---:|---:|---:|
| 0 µW (약한 프로브 극한) | 39.2663% | 39.2789% | +0.0126%p |
| 100 µW | 46.3622% | 67.3523% | +20.9901%p |

0 µW에서 남은 차이는 선폭 규약에서 왔다. AutoOD는 통과 완화율을 광학 균일 반치반폭(HWHM)에 더한다. GABES 쪽 전폭(FWHM)에 200 kHz를 더해 맞추자 2,001점 전체에서 투과율 분율의 최대 절대차가 5.55×10⁻¹⁶이었다. 이렇게 선폭을 맞춘 100 µW 비교에서도 차이는 21.1610%p였다. 두 계산값의 차이가 독립 측정에서 어느 쪽의 잔차가 작은지 알려 주지는 않는다. 열린 전이에서 프로브에 의한 광펌핑이 약한 프로브 조건에 미치는 영향은 [Rb D선 흡수 실험](https://arxiv.org/abs/0805.1139)에서도 확인된다.

재현 경로는 AutoOD 0.2.2(엔진 핀 `8846193ffcef`)의 `calculate(Settings(...))`와 제품 GABES `246af301e053`의 `SASScheme._compute_species` → `headless_observables`다. 두 Python 프로세스에서 AutoOD의 조건과 2,001점 주파수 축을 전달했다. GABES 입력축은 `scan_rad_s = x_GHz × 2π × 10⁹`이고, 표는 0부터 센 1164번 표본에서 직접 읽었다. 보간을 사용하지 않았다.

1. **공용화 전후의 수치 보존.** AutoOD의 `ZeemanProbe`와 `_population_response`에서 자기 부준위 구성·강도별 흡수 응답을 GABES로 옮긴다. 이미 공용인 [점유율 계산](../../gabes/optical_pumping.py), [Voigt 선모양](../../gabes/linear_hyperfine.py), [Gaussian 빔 전파](../../gabes/probe_saturation.py)는 그대로 사용한다. 양 앱의 기존 경로를 각각 기준으로 고정하고, 이전·새 구현의 주파수 축, T, OD₀, OD_eff, 표시 판독을 대조한다. 기본값과 재계산 입력 양 끝에서 바이트 일치를 우선하며, 프로젝트의 상대차 10⁻¹² 예외를 쓰면 모든 표시값 일치와 차이를 기록한다.
2. **기본값 전환.** 공용화가 확인되면 별도 모델 변경으로, 지원 영역에서 이론 계산·피팅 잔차·내보내기·AutoOD가 같은 GABES 함수를 사용한다. 새 기본 약한 프로브 곡선과 유한 파워 곡선은 AutoOD의 통과 완화 선폭 규약을 공유한다. 추가 선폭 피팅에서도 통과 기여는 한 번만 포함한다. 같은 조건에서는 피팅 전의 두 화면이 같은 스펙트럼을 보여야 한다. 기존 모델 대비 변화량을 기록하고 구버전 설정은 원래 모델로 재생할 수 있게 식별자를 보존한다. GABES 고유의 Cs·완충가스·분할 셀 등은 기존 모델과 적용 범위를 표시한다. SAS 이론은 왼쪽에서 계속 제공한다.
3. **물리 검증과 피팅 검증.** 자연비·순수 동위원소·혼합비, D₁/D₂, 0 µW의 Exact·기존 속도 격자 선택, 양의 파워에서 약한 프로브 극한, 온도·빔 크기·셀 길이를 검사한다. 미소 양의 파워가 Exact 약한 프로브 곡선에 접근하는지, 점유율 합과 전파가 보존되는지 확인한다. 추정할 물리 변수는 합성 측정의 회수 오차·잔차·상관과 독립 측정의 검증 여부를 구분해 공개한다. 분포형 통과시간 모델은 별도 연구 항목으로 유지한다.

## ⟦AI⟧ 정밀 피팅의 적용 범위

| 조건 | 제안 |
|---|---|
| 정량 보정된 약한 프로브 OD | 기존 [물리 피팅](../../gabes/od_spectrum_fit.py)을 먼저 연결한다. 균일 셀, 분광선이 지정된 Rb·Cs, 펌프·프로브 파워 입력 모두 0인 약한 프로브 경로, 보정된 주파수와 절대 투과율이 대상이다. 취득 방향을 하나 골라 온도·셀 길이·추가 선폭·주파수 오프셋 중 필요한 항목만 추정한다. 기존 잔차·불확도·변수 상관 및 별도 검증 구간을 유지한다. |
| 임의 단위 전압 또는 주파수 영점 미확정 | 빠른 피팅과 수동 겹쳐보기를 제공한다. 정량 피팅을 열면 필요한 보정과 그 입력 위치를 보여 준다. 상대 신호의 높이나 표시용 Y 배율을 절대 투과율로 해석해 물리값을 확정하지 않는다. |
| 유한 프로브 Rb OD | 위 지원 영역의 이론선과 최적화는 공용 자기 부준위 모델로 통일한다. 파워·빔 크기·동위원소 비율 추정은 변수별 회수값·불확도·식별 가능성을 확인한 범위부터 연다. |
| 기타 OD 조건 | 해당 GABES OD 모델이 제공하는 판독값과 검증된 변수만 사용한다. 모델 전환이 필요한 조건에서는 적용 가능한 범위를 화면에 표시한다. |

**단위와 영점도 검증 항목이다.** 예를 들어 AutoOD의 1/e² 빔 직경 2 mm는 GABES의 반경 1 mm다. AutoOD의 Rb 주파수축은 ⁸⁵Rb 기준이지만 GABES의 순수 ⁸⁷Rb 조건은 ⁸⁷Rb를 기준으로 삼을 수 있다. GHz↔MHz 환산, 영점 변환, 사용자가 맞춘 표시용 오프셋을 분리해 기록한다. 측정 영점이 명시되지 않은 파일은 그 상태를 보존한다. 모델마다 산출하는 OD₀·OD_eff·T·유효 원자 수의 의미도 함께 확인한다.

## ⟦AI⟧ CSV 호환과 디자인

- **호환 방향.** GABES는 AutoOD 0.2.2 일반·Origin 비교 파일에서 원본 X·신호, 단위·신호 유형을 읽는다. GABES가 쓴 비교 파일은 생성 앱, 포맷 버전, GABES 모델·버전, 축 기준과 적용값을 기록하고 GABES에서 재열기를 보장한다. AutoOD 0.2.2는 자체 생성 표식과 일부 Rb 전용 헤더를 검사한다. 기존 EXE로 건네야 할 때는 2열 측정 CSV와 명시적 단위 선택을 호환 경로로 삼고, 전체 포맷의 양방향 호환은 데스크톱 판독기를 연결한 뒤 검증한다.
- **파일 크기.** 일반 입력의 10 MiB 제한과 자체 비교 파일의 검증된 확장 포맷을 구분한다. 업로드 위젯·배포 환경의 전송 한도, 파서의 스키마·행 한도, 보기 전환 시 파일을 보관하는 경로를 함께 맞춘다. 대용량을 허용하려고 모든 일반 CSV의 한도를 풀 필요는 없다.
- **화면.** [GABES 테마](../../gabes_ui/theme.py)의 단색 배경·플롯, IBM Plex 글꼴, 잉크색 본문을 유지한다. 조건·실험 스펙트럼 제목에는 같은 하늘색 계열의 아주 옅은 그라데이션을 제목 띠에만 쓰고, 선택점 카드에는 더 눈에 띄게 쓴다. 입력 행은 중립색이고 드롭다운·숫자 입력·손잡이가 테두리·높이·포커스 표시를 공유한다. [그래프 팔레트](../../gabes/plot_style.py)의 하늘색 이론선과 로즈색 측정선을 범례·선 모양으로도 구별한다. 이 단계의 스타일 적용 범위는 CSV 보기다.
